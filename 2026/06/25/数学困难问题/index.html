离散对数问题（Discrete Logarithm Problem，DLP）

设G\mathbb{G}G为有限乘法群,g∈Gg \in \mathbb{G}g∈G是阶为qqq的元素,给定X∈<g>X \in <g>X∈<g>,求解唯一0≤x≤q−10\le x\le q-10≤x≤q−1满足

<g>={gi:0≤i≤q−1}<g> = \{ g^i : 0 \le i \le q-1 \} <g>={gi:0≤i≤q−1}

计算Diffie-Hellman问题(computational Diffie-Hellman,CDH)

设G\mathbb{G}G为有限乘法群,g∈Gg \in \mathbb{G}g∈G是阶为qqq的元素,给定gx,gyg^x,g^ygx,gy,计算gxyg^{xy}gxy。

容错学习(LWE)问题

容错学习(learning with errors,LWE)问题最早由Oded Regev提出,目前尚无概率多项式时间(量子)求解算法,属于NP难问题。

对于一般的线性方程组:

LWELWELWE问题及其判定问题目前均无(量子)概率多项式时间求解算法。

Ring LWE

将最基础的LWELWELWE问题的工作空间扩展至Rq=Zq[x]/(xn+1)R_q = \mathbb{Z_q}[x]/(x^n + 1)Rq​=Zq​[x]/(xn+1)就得到了基于环的 LWELWELWE问题(Ring LWE),此时每个元素都是不再是整数而是多项式:

a(x)=a0+a1x+⋯+anxna(x) = a_0 + a_1x + \cdots + a_n x^n a(x)=a0​+a1​x+⋯+an​xn

环具有很好的代数结构,可以使用NTT加速运算,但是其特殊的数学结构被认为安全性不如一般的LWELWELWE问题。

Module LWE

进一步将工作空间搬至RqkR_q^kRqk​上,如k=3k = 3k=3,此时秘密

s=(s1,s2,s3)s = (s_1, s_2, s_3) s=(s1​,s2​,s3​)

每个sss都变成一个多项式,此时AAA变成了多项式矩阵,整个计算t=As+et = As + et=As+e完全类似于LWELWELWE问题,当同样可以使用NTT加速。不同于RIing LWE的是,这里采用的AAA是一个由多个多项式构成的矩阵而不是循环矩阵,被认为有更高的安全性。
