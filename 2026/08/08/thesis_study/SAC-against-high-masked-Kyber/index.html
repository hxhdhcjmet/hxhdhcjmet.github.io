(2024) A Side-Channel Attack on a Higher-Order Masked CRYSTALS-Kyber Implementation
Author: Christina Pöpper; Lejla Batina; Ruize Wang; Martin Brisfors; Elena Dubrova;
Journal: , 14585: 301-324, 2024.
Journal Tags:
Local Link: Wang 等 - 2024 - A Side-Channel Attack on a Higher-Order Masked CRYSTALS-Kyber Implementation.pdf
DOI: 10.1007/978-3-031-54776-8_12
Abstract: In response to side-channel attacks on masked implementations of post-quantum cryptographic algorithms, a new bitsliced higherorder masked implementation of CRYSTALS-Kyber has been presented at CHES’2022. The bitsliced implementations are typically more difﬁcult to break by side-channel analysis because they execute a single instruction across multiple bits in parallel. However, in this paper, we reveal new vulnerabilities in the masked Boolean to arithmetic conversion procedure of this implementation that make the shared and secret key recovery possible. We also present a new chosen ciphertext construction method which maximizes secret key recovery probability for a given message bit recovery probability. We demonstrate practical shared and secret key recovery attacks on the ﬁrst-, second- and third-order masked implementations of Kyber-768 in ARM Cortex-M4 using proﬁled deep learning-based power analysis.

📜 Research Core

Contributions

  • 发现了高阶掩码在Kyber上实现的新的易受攻击的点，即在re-encryption过程中Boolean to Arithmetic转变的过程。
  • 提出了一种新的选择密文构建方法，对于一个给定的信息比特可以最大化密钥恢复的概率。
  • 证明(实现)了现实中在ARM Cortex-M4上的基于profiled deep learning-based power analysis 的对Kyber768实现 ω\omegaω 阶掩码的密钥恢复攻击。

⚙️ Content

Attack Description

  • 攻击者目标为提取共享信息KKK和/或恢复长期私钥sksksk，其中获取长期私钥sksksk自然蕴含着获取到了共享信息KKK，反之则不然(很自然，因为恢复了sksksk就能解密ctctct,能自行算出共享信息KKK,反之仅有共享信息KKK未必能恢复出sksksk)。

  • Profiling stage:构建模板阶段，攻击者多次重复以下过程:

    • 使用KYBER.CCAKEM.KeyGen()生成密钥对 (pk,sk)(pk,sk)(pk,sk) ，均匀随机生成消息 mpm_pmp​ ，使用KYBER.CCAPKE.Enc()加密 mpm_pmp​ 得到 cpc_pcp​ 。
    • 利用上述 mp,pkm_p,pkmp​,pk 调用Encaps()计算得到 (c,K)(c,K)(c,K) 。
    • 在分析设备运行KYBER.CCAKEM.Decaps()，解封装每一个 cpicp_icpi​ 并测量得到对应能量消耗 tritr_itri​ 。

    注意， cpicp_icpi​ 对应的明文信息 mpimp_impi​ 我们是知道的，后面训练模型用的数据是 mpmpmp 和 trtrtr

    重复过程足够多次，收集到足够多数据后，再利用数据集(mp,tr)(mp,tr)(mp,tr)训练一个神经网络模型M\mathcal MM，该模型可以从KYBER.CCAKEM.Decaps()的能量消耗泄露(trace)识别出对应的信息mmm。

  • 由于ChipWhisperer-Pro的缓冲区原因，无法采集masked_poly_frommsg()过程的所有数据，因此对于1、2阶掩码，收集包含前33bit信息的traces用于训练；而对3阶掩码，则收集包含前17bit信息的traces用于训练。
  • 在[9]中使用了true random number generator(TRNG)和范围检查机制，用于生成掩码，导致了traces的未对齐问题(相同操作在不同的时间点(即采样点)上发生，标准化后会被抹平)。本论文采用cross-correlating with templates的方法来对齐，即为每个泄露点建立模板，其他traces滑动并与模板计算互相关系数，得到的相关系数最大时就认为对齐了，以此方法实现所有traecs的对齐。
